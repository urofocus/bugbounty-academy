Module 01

The Command Line (CLI)

Hackers don't rely on graphical interfaces. To truly control a computer, you must learn to speak to it directly.

1. The Theory

Most people interact with computers using a mouse to click icons. This is the Graphical User Interface (GUI). However, underneath every GUI is a shell—a program that takes text commands and passes them to the operating system to execute.

Why do bug bounty hunters use the Command Line Interface (CLI)?

  • Speed: Typing commands is vastly faster than clicking through menus.
  • Automation: You can script hundreds of commands to run automatically.
  • Control: Many powerful hacking tools do not even have a GUI.

2. The Example

One of the most basic things you need to know when you break into a system is: "Who am I currently logged in as?"

# Check your current user identity:
whoami

# Example Output:
root
